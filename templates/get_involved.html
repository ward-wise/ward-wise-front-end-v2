You can build things.

Pick an idea someone nominated, build it in a repo of your own, and the site picks it up.

Build a nominated measure

Each idea below is a ticket. Claim one by commenting on it, start a new repo from the measure template, and link the repo on the ticket. You don't need access to anything of ours.

  1. Claim an idea with a comment on its ticket.
  2. Start a repo from measure-template and compute a fine-grained layer: points, a raster, or values on census tracts.
  3. Describe it in aggregation_spec.json and check it with byop validate.
  4. Publish a release and open a pull request adding it to ward-wise-measures. Once it merges, it appears for every ward and neighborhood.
