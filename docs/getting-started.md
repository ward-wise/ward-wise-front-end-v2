# Getting Started

## Prerequisites
This project uses the Bun runtime to run its Javascript code (or more specifically, TypeScript). You'll need to download Bun.

Visit https://bun.com/docs/installation and follow the installation instructions for your system.

## Project Setup
Clone the repo and switch to the `dev-react` branch. Then install the required dependencies for this project like so:
```bash
git clone https://github.com/ward-wise/ward-wise-front-end-v2.git
cd ward-wise-front-end-v2
git checkout dev-react

bun install
```

You can start a dev server and view the site locally in your browser by running the following command:
```bash
bun dev
```
then opening http://localhost:3000 in your browser.
